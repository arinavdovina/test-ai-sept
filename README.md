# FreshTeacher — Осенний календарь промптов

Готовый статический сайт для GitHub Pages. Никакой сборки, npm и базы данных не нужно.

## Что уже настроено
- календарь с 15 по 30 сентября 2026;
- ежедневная разблокировка ровно в 10:00 по Москве (UTC+3);
- до разблокировки используется чёрно-белая версия иллюстрации, после — цветная;
- внутри каждого дня 3 готовых промпта для генерации рабочих листов;
- кнопки копирования одного промпта и всего дневного набора;
- адаптивная версия для телефона/планшета;
- progress bar и автоматический статус следующего открытия;
- новый scrapbook-фон в тёплой осенней палитре;
- все изображения локальные, внешние сервисы не нужны.

## Как опубликовать на GitHub Pages
1. Создайте новый репозиторий на GitHub.
2. Загрузите **всё содержимое этой папки** в корень репозитория.
3. Откройте `Settings → Pages`.
4. В `Build and deployment` выберите `Deploy from a branch`.
5. Выберите ветку `main` и папку `/ (root)`, затем `Save`.

Через несколько минут GitHub покажет адрес опубликованного сайта.

> Важно: логика открытия работает по реальному времени. На 17 сентября после 10:00 МСК автоматически доступны 15, 16 и 17 сентября. После 30 сентября будут доступны все карточки.
